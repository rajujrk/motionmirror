# MotionMirror (provisional name)

A private video-editing application. A user uploads a source dance video, selects one dancer, and uploads photographs of
themselves. The application generates an edited video in which the user's appearance replaces that dancer while following the
source performance. Likeness, anatomy and foot contact are quality targets, not guarantees.

**Status:** under construction. See [`docs/IMPLEMENTATION_STATUS.md`](docs/IMPLEMENTATION_STATUS.md). No real GPU validation has
been performed.
